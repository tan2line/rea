Every scanned server

Sorted by weekly npm downloads. Click a heading to sort. Effects link to the first call site in the detail report.

Method: each package tarball was downloaded from npm and analyzed with REA (static JavaScript application analysis, which produced the Evidence record cited per row) plus a scanner-owned syntax pass that records process spawns, filesystem writes, network requests, dynamic code, environment reads and literal hosts with file and line. Grading is deterministic and fails closed: unresolved unknowns or code-executing effects yield Restricted, and a human issuer is always required for full privileges.

Limits: findings are source-syntax candidates, not proof of runtime behavior. Only the package's own files were scanned, so a thin wrapper grades on its wrapper code and declared dependencies count as an unknown. Minified bundles degrade effect recovery and are flagged.
